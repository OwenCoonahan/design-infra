# Roadmap

Planned work, updated 2026-10-18. Items below are not shipped features.

- [ ] **Public changelog.** A clean `/changelog` page where people can see what is new, improved and fixed. Use dated release entries, short user-facing descriptions and links to the relevant galleries, sources or features. Link it from site navigation. Maintain one structured release source so the site and repository stay consistent. Only describe changes as shipped after production verification; keep plans separate. Include concrete additions such as chart collections, live previews and integration improvements rather than a raw commit feed. Verify that dates, links and mobile presentation are readable.
- [ ] **More live chart styles.** Start with twelve useful chart examples/treatments, comparing several UI collections on consistent sample data. Keep external examples and hosted demos clearly distinguished. See [Charts and previews](CHARTS-AND-PREVIEWS.md).
- [ ] **Focused chart browsing.** Evolve the current form/treatment filters into a dedicated chart experience in this repository, with real interactions and agent handoff. Review concrete design options before building a new workbench layout.
- [ ] **Agent contributions and feedback.** Develop the proposal in [Agent contributions](AGENT-CONTRIBUTIONS.md), including explicit user control over what is shared.
