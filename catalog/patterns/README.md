# Patterns

Short, opinionated notes on *how* to use a component pattern well — anatomy, states, a11y,
which catalog entries implement it best. One file per pattern, named after the
[component.gallery](https://component.gallery/components/) slug (e.g. `hero.md`, `pricing.md`,
`agent-status.md`).

Template:

```md
# <Pattern>
component.gallery: https://component.gallery/components/<slug>/
## When to use / not use
## Anatomy & states
## Accessibility musts
## Best implementations
- oc/… — why
- aceternity/… — why
```
