# D3

Low-level visualization tools for bespoke scales, shapes and layouts.

## Use it well

Use existing chart components first when they fit. D3 is a composition toolkit, not a ready-made UI. Assign DOM ownership carefully in React and budget for axes, interaction and accessibility.

Install one suitable engine for the task. Existing shadcn charts remain useful for conventional React dashboards. Chart engines and integration recipes do not become complete application components just by installing their npm package.

## Install

```bash
pnpm add d3
```

Check the consuming project's installed versions first; preserve its stack and theme. Renderer support is a library capability: alternate renderers or plugins can require additional dependencies. Provide real data, units, loading/empty/error states and an accessible table or explanation.

## Starting patterns

- [Custom chart scales](https://d3js.org/d3-scale) — Map measured values into positions and sizes. Install: `pnpm add d3`.
- [Custom chart shapes](https://d3js.org/d3-shape) — Compose lines, areas and arcs. Install: `pnpm add d3`.
- [Hierarchy layouts](https://d3js.org/d3-hierarchy) — Explore trees and nested structure. Install: `pnpm add d3`.
- [Force-directed layouts](https://d3js.org/d3-force) — Arrange connected entities through a simulation. Install: `pnpm add d3`.
- [Region selection](https://d3js.org/d3-brush) — Select a region within a chart. Install: `pnpm add d3`.
