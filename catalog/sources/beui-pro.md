# beUI Pro — future paid option

Useful for application workflows, agent interfaces and larger composed sections. Moods: refined and technical. The maintainer plans to buy paid libraries eventually; **the current pilot uses free components**. These entries are paid, link-only references. Default agent searches and gallery browsing exclude them unless paid results are explicitly enabled. Use [beUI free](https://beui.dev/) now.

## Future installation

After the user confirms licensed access, follow the vendor's [installation guide](https://pro.beui.dev/components/installation). The private `@beui-pro` registry uses a bearer token from `BEUI_PRO_TOKEN`; some blocks also depend on public `@beui` primitives. Keep credentials outside repositories. The Pro registry, MCP and purchasing flows are not enabled by this addition. Do not interpret a future purchase plan as authorization to buy or install paid items.
