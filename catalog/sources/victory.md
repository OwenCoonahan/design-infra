# Victory

Composable React chart components with theme and interaction containers.

## Use it for

This indexes Victory for web; Victory Native is a different integration. Compose axes, labels and containers and map themes to existing brand tokens. Confirm React peers and client/server behavior in the consumer. A package install is not a prebuilt dashboard.

Moods: technical, refined. Compare its chart form and treatment with the project’s existing components before adding another library.

## Install selected packages

```bash
pnpm add victory
```

Choose versions compatible with the current project; do not change its framework, theme or UI system automatically. The command installs the packages, not a finished component or screen. Read the linked API/example and adapt it to actual data and design tokens.

## Starting options

- [Line chart](https://nearform.com/open-source/victory/docs/charts/line) — Compose trends with a custom chart theme.
- [Bar chart](https://nearform.com/open-source/victory/docs/charts/bar) — Compare categories with configurable bar shapes.
- [Area chart](https://nearform.com/open-source/victory/docs/charts/area) — Filled trend regions with shared axes.
- [Pie chart](https://nearform.com/open-source/victory/docs/charts/pie) — Labeled part-to-whole sectors.
- [Scatter plot](https://nearform.com/open-source/victory/docs/charts/scatter) — Render observations with configurable point symbols.
- [Candlestick chart](https://nearform.com/open-source/victory/docs/charts/candlestick) — Show open/high/low/close observations.
