# AG Charts Community

Free Community chart types for framework-neutral dashboard and reporting interfaces.

## Use it for

Only ag-charts-community is indexed. Register the current Community modules as documented; Enterprise modules, gated chart types and paid interactions are excluded. React/Angular/Vue wrappers are optional separate integrations. Confirm version-matched modules and size the chart container; destroy chart instances on unmount.

Moods: technical, refined. Compare its chart form and treatment with the project’s existing components before adding another library.

## Install selected packages

```bash
pnpm add ag-charts-community
```

Choose versions compatible with the current project; do not change its framework, theme or UI system automatically. The command installs the packages, not a finished component or screen. Read the linked API/example and adapt it to actual data and design tokens.

## Starting options

- [Line chart](https://www.ag-grid.com/charts/javascript/line-series/) — Community trend lines with chart themes.
- [Bar chart](https://www.ag-grid.com/charts/javascript/bar-series/) — Community category bar comparisons.
- [Area chart](https://www.ag-grid.com/charts/javascript/area-series/) — Community filled trend series.
- [Pie chart](https://www.ag-grid.com/charts/javascript/pie-series/) — Community part-to-whole sectors.
- [Scatter plot](https://www.ag-grid.com/charts/javascript/scatter-series/) — Community paired numeric observations.
